# Owner checks on the phone: T7-shields

Install the new APK from the GitHub Actions run for branch `claude/T7-shields` (it installs over the old Deliverance).

## A. The four shields on Home
1. Press the Home button. Look at the four shields around the round Claude button.
   You should see: each shield has a small gold line drawing: X = a raven (bird), Discord = a goblet, YouTube = a scroll with a play mark, Messages (Google Messages if installed, else Samsung Messages) = a letter with a red wax seal.
   You should NOT see: a coloured app logo on any shield.
2. Look at the wax-seal dock at the very bottom.
   You should see: it looks exactly as before (Herald, Portrait, Road, Smithy). Nothing changed there.

## B. Picking other apps
1. Hold your finger on one shield for a second. The app list opens. Choose Google Maps.
   You should see: the shield now shows a gold compass, and the name MAPS under it.
2. Repeat with Phone (a bell), Camera (an eye), Chrome or Brave (a ball with a cross), Settings (a ship's wheel), Gallery, Clock, Calendar, Spotify, WhatsApp, Gmail.
   Report: which ones showed a coloured logo or a letter shield instead of the gold drawing (name the app). Some phone apps may use a name the launcher does not know yet; a letter shield there is expected, a coloured logo is not.
3. Choose an app with no drawing, for example Calculator.
   You should see: a small gold shield with the app's first letter in old gothic writing (C).
   You should NOT see: the coloured app icon.

## C. Badge and restart
1. Send yourself a notification from an app that sits on a shield (for example a message to Discord or Messages).
   You should see: the red number badge at the top right of that shield, on top of the drawing.
2. Close the launcher fully (recent apps button, swipe Deliverance away) and open it again.
   You should see: your picks are still on the shields with the same drawings.
