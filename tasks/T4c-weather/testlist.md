# Owner checks on the phone: T4c-weather

Before you start: install the new APK. Make sure Android location is ON (swipe down from the top of the screen, the "Location" tile should be lit).

1. Open the launcher (press Home). Look under the clock at the top right.
   - Right after install you should see one of these short texts: "Allow location", "Fetching weather…" or the real temperature.
   - Report which one you see.
2. If it says "Allow location": tap it. A box appears asking for location. Choose "While using the app" (or "Allow"). Go back to Home.
   - You should see "Fetching weather…" and, within about a minute, a temperature (in °F) with a word like "Clear", plus the little scene.
3. If it says "Fetching weather…": wait one minute without touching anything.
   - You should see the temperature and the scene.
   - If instead it says "Weather unavailable", tap it (it opens the weather settings) and report what the settings screen shows.
4. Should NOT happen: the text must not stay on "Tap to set up weather" now that a provider is picked. It also must not stay on "Fetching weather…" forever (after a minute it must change to the temperature or "Weather unavailable").
5. Restart check: swipe the launcher away from recent apps, open it again.
   - The temperature should come back (it may take a few seconds). It must not ask you to set up again.
6. Fallback if step 3 ends on "Weather unavailable" or location never works:
   - Tap the weather text (or long-press the header) to open settings, then go to Integrations > Weather.
   - Turn off the automatic location switch, tap the location row, type your city (for example "Seattle"), tap your city in the list.
   - Go back to Home. Within a minute you should see the temperature. Report what you see.

Report back: what the weather text said at each step, and the words you saw.

Extra: if the text says "No weather for your area", report it and tell me roughly where you are (city only). That means Bright Sky has no station near you and we will add another source.
