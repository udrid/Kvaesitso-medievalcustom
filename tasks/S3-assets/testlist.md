# S3-assets: what to do on the phone (after you approve the push and the build is green)

Nothing here changes the Deliverance app itself. You set pictures and install up to three small icon-pack apps.

## A. Get the files onto the phone
1. On the computer, open the GitHub page of the project, Actions, "Build icon pack APKs", Run workflow, wait for green, download "deliverance-icons-apks" and unzip it. (I will tell you when it is ready.)
2. Copy to the phone (cable, or email to yourself): the three APK files (pack-heater, pack-seal, pack-bare), and from the folder `assets`: `wallpaper/deliverance-orb-1080x2400.png`, the seven files in `aod/`, and `keyboard/swiftkey-vellum-1080x1000.png`.
3. You should see them all in the phone's Gallery or My Files. Report if any is missing.

## B. Lock screen picture (pick 1C)
1. Open the Gallery, open `deliverance-orb-1080x2400.png`, tap the three dots, "Set as wallpaper", choose "Lock screen" only. (Not "Home screen": Deliverance draws its own Home.)
2. Lock the phone and wake it. You should see the glass orb with red jewels low on the screen, and Samsung's clock and notifications above it.
3. Report: does the clock or a notification cover the orb or its ring text?
4. Should NOT happen: the picture showing behind the Deliverance Home screen, or the orb cut off at the sides.

## C. Always-on display (pick 2B)
1. Settings, Lock screen, Always On Display, switch it on, then "Clock style". Look for an "Image" tab and add a picture from the Gallery. Use today's file from `aod/`: sol = Sunday, luna = Monday, mars = Tuesday, mercury = Wednesday, jupiter = Thursday, venus = Friday, saturn = Saturday.
2. Lock the phone. You should see the day sign and name in dim gold on black, plus Samsung's own clock.
3. Report: can you pick your own picture there at all? Does it show the picture and the clock together? If there is no Image option, say so.
4. Should NOT happen: a bright grey box behind the picture. (Changing the file each day is by hand; automatic change needs Good Lock.)

## D. Good Lock (pick 7A: you check)
1. Open the Galaxy Store app and search "Good Lock".
2. Tell me exactly what you see: a download button, "not available in your country", or nothing found. If it installs, tell me which modules it lists (Theme Park, LockStar, ClockFace, QuickStar, NavStar).

## E. The icon pack
1. Install ONE pack first, `pack-heater`: tap it in My Files, tap Install (allow "install unknown apps" for My Files if asked).
2. Open Deliverance, Settings, Icons, Icon pack. You should see "Deliverance Icons (Heater)". Choose it.
3. Open the app list. Apps like Phone, Camera, Chrome, Settings and Gallery should have a gold emblem on a dark shield. Other apps keep their own colour icon, small, on a gold-rimmed shield.
4. Report: the apps that did NOT get an emblem (names, one per line, or a screenshot of the app list). I fix the app mapping from this list, because the names I used are from memory.
5. Optional: install `pack-seal` (round plate) and `pack-bare` (emblem only) and switch between them in the same setting.
6. Should NOT happen: blank icons, a crash, or the four Home shields changing (the launcher draws them itself and they stay as they are).
7. Restart check: Settings, Apps, Deliverance, Force stop, then open Deliverance again. The chosen icon pack must still be selected.
8. To theme one app by hand: long-press it, Customize, Icon, pick the pack, pick any emblem.

## F. Keyboard (SwiftKey, pick 6A)
1. Open SwiftKey, tap Themes, then the "Custom" tab, then Start. Add the picture `swiftkey-vellum-1080x1000.png`.
2. Move the brightness slider until the faint ring shows but the letters are easy to read. Choose the darkest key shade, key borders ON, and the gold or amber pop-up colour if the list has one. Name it and save.
3. Open any app and bring up the keyboard. You should see dark keys on the charcoal picture.
4. Report: which colour names the pop-up list offers, and whether the picture is cropped oddly.
5. Should NOT happen: unreadable letters, a white strip, a stretched ring.
